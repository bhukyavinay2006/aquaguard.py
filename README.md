# AquaGuard - Smart Water Usage Monitor

## Project Description
AquaGuard is a Python-based application that monitors
household water consumption and helps users save water.

## Features
1. Record Water Usage
2. View Daily Usage Report
3. View Complete Usage History
4. Check Daily Water Limit
5. Detect Unusual Water Usage
6. Set Daily Water Limit
7. Calculate Water Bill
8. View Water Usage Graph
9. Water Saving Tips

## Technologies Used
- Python
- CSV
- Matplotlib

## Required Library
pip install matplotlib

## How to Run

python aquaguard.py
